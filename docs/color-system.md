# 🎨 Color system

The current interface is built around a pale neutral background, white surfaces, dark slate text, muted metadata, and indigo/blue emphasis. The banner adds a violet gradient as a decorative project identity element.

## Semantic use
| Meaning | Intended use |
| --- | --- |
| Primary accent | Action buttons, department labels, links |
| Main text | Headings and employee names |
| Muted text | Metadata and supporting copy |
| Border | Surface separation |
| Error | Error panel border/text where needed |
| Focus | Visible keyboard outline |

## Contrast
The current palette has not been measured against a complete WCAG 2.2 AA contrast matrix. Do not assert full compliance. For new combinations, verify text contrast using a contrast analyzer, and do not use a subtle tint as the only indicator of an interactive or error state.
