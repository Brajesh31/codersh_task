# 🍪 Cookies and tracking status

The application code does not create cookies or include an analytics/session-replay library. It uses browser localStorage for the search term and selected department. localStorage is not a cookie, but it is still browser storage and should be disclosed accurately.

The static hosting provider, GitHub Pages or another selected host, and external image providers may have their own logging, cookie, or privacy practices. This repository does not configure or control those third-party behaviors.

If analytics, advertising, account sessions, or other tracking is introduced, document the technologies, purposes, consent requirements, retention, and opt-out process before release.
