# 🧰 Technology stack

| Layer | Technology | Current use |
| --- | --- | --- |
| UI | React 19 | Functional components and state |
| Page composition | React component tree | Single directory screen; no routing dependency |
| Build tooling | Vite 8.3.8 | Development server and bundling |
| HTTP | Browser Fetch API | Static JSON request; no HTTP client package |
| Data | JSON | Public local asset |
| Browser persistence | localStorage | Search and department preferences |
| Styling | CSS | Responsive layout and dialog styling |
| Static analysis | ESLint 10.15 | JavaScript and JSX linting |
| Unit tests | Node.js test runner | Pure data helper behavior |
| Automation | GitHub Actions | CI, CodeQL, docs validation, dependency review |

No server framework, ORM, database engine, authentication provider, analytics platform, or UI component library is currently used.
