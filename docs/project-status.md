# 📍 Project status

**Status:** Functional frontend prototype with active repository maintenance.

## Implemented
- React/Vite root route.
- Public JSON fetch and record normalization.
- Search by name/email and exact department filter.
- Employee card and profile dialog.
- Loading, empty, error, and retry states.
- Browser preference persistence.
- Node unit tests for data helper functions.
- Lint/test/build CI and documentation/security workflows.

## Not implemented
- Backend, database, authentication, authorization, employee editing, audit history, analytics, and server-side pagination.
- Automated browser end-to-end tests.
- Formal security or WCAG audit.
- Production hosting configuration or confirmed live deployment.

## Release status
Package version remains `0.0.0`; no formal release is declared. The current default branch is the source of truth. See [Roadmap](../ROADMAP.md) for possible next work.
