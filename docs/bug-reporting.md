# 🐛 Bug reporting

Use the repository's bug issue form for reproducible application defects. Include:
- A concise summary.
- Browser, operating system, and viewport.
- Steps to reproduce.
- Expected and actual behavior.
- Safe console/network error details.
- The affected commit if known.

## Privacy rule
Do not upload the employee JSON, real employee records, screenshots containing personal information, browser storage values, passwords, or access tokens. Replace names and emails with synthetic examples.

For an accessibility problem, use the accessibility form. For a security vulnerability, do not use a public bug issue; follow [SECURITY.md](../SECURITY.md).
