# 📘 WCAG 2.2 AA guidance

WCAG 2.2 AA is a target for future verification, not a certification or current compliance claim.

## Relevant checks for this UI
- **Perceivable:** meaningful text alternatives, readable contrast, zoom/reflow, and labels.
- **Operable:** keyboard access to filters/cards/dialog, visible focus, sensible focus order, and sufficient target size.
- **Understandable:** clear labels, predictable filtering, understandable errors, and consistent controls.
- **Robust:** valid semantic structure and accessible names that assistive technology can interpret.

## Evidence expected
For each relevant criterion, record the page/component, test method, browser, assistive technology if used, result, and unresolved issue. Automated scans can identify some defects but cannot establish full WCAG conformance.

## Current gaps to verify
Contrast combinations, 200-400% zoom/reflow, screen reader announcements, focus behavior with browser/screen-reader combinations, and mobile target spacing need real testing.
