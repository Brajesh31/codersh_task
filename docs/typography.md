# 🔤 Typography

The current design uses a system sans-serif stack with a clear size hierarchy: large page heading, compact eyebrow label, readable subtitle, card name, muted metadata, and smaller supporting labels.

## Guidelines
- Use headings in document order.
- Keep paragraph line length comfortable for reading.
- Use font weight to establish hierarchy rather than color alone.
- Avoid shrinking essential employee or department information to fit a card.
- Allow emails and long department labels to wrap.
- Preserve browser zoom and text resizing.

No custom font is downloaded by the application. This reduces external font requests and avoids a separate font-license requirement.
