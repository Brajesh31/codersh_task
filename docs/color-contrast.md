# 🌈 Color contrast

The UI uses dark text on white/near-white surfaces and indigo accents. Contrast must be checked for each foreground/background pair, including muted labels, disabled controls, links, focus outlines, and department chips.

## Review checklist
- Normal text should meet the applicable WCAG AA contrast threshold.
- Large text should meet the applicable large-text threshold.
- Focus and non-text control boundaries must remain visible.
- Disabled controls must still communicate their disabled state clearly.
- Do not use color alone for warnings, empty results, or errors.

No complete measured contrast report exists yet. Do not state a contrast ratio or WCAG pass until it has been measured against the actual computed CSS colors.
