# 🏷️ Versioning

The package currently reports version `0.0.0`, reflecting an unreleased development project. No formal release history or compatibility promise has been published.

## Proposed convention
When the project begins making public releases, use semantic versioning:
- MAJOR for incompatible public behavior or data contract changes.
- MINOR for backward-compatible features.
- PATCH for backward-compatible fixes.

Tag source commits with a matching `vX.Y.Z` tag and record user-visible changes in CHANGELOG.md. Update CITATION.cff when a real version is released.

Do not create version badges or release pages until a version has actually been published.
