# 📸 Application screenshots

No screenshots are committed at this time. This is intentional: a screenshot should come from a real, running build, not a mockup that could be mistaken for the implementation.

When capturing screenshots:
1. Run `npm ci` and `npm run dev` or serve a verified production build.
2. Use only synthetic employee records and example.invalid email addresses.
3. Capture the directory, filtered results, profile dialog, and a narrow viewport if these views are visually useful.
4. Record browser, viewport size, and commit hash.
5. Save optimized images in this directory and add meaningful alt text in README.
6. Re-check the images for personal data, browser notifications, credentials, or unrelated desktop content.
