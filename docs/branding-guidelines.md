# 🪄 Branding guidelines

The project identity uses a simple people-and-directory motif, supported by an indigo-to-violet gradient and neutral surfaces. The logo and banner are original SVG assets stored in `docs/assets/`; the favicon variant is `public/employee-directory.svg`.

## Use
- Keep the project name "Employee Directory".
- Use the logo/banner for project identity, not as evidence of extra product features.
- Preserve accessible alternative text for meaningful images.
- Keep SVG dimensions and viewBox scalable.
- Avoid unlicensed third-party photos or logos.

## Do not imply
Do not brand the project as an HR suite, workforce platform, admin console, payroll product, or secure employee management system. Those capabilities do not exist.
