# Code of Conduct

This project welcomes contributors with different backgrounds and experience. Everyone participating in project spaces should help make them respectful, useful, and welcoming.

## Expected behavior

- Be considerate, patient, and constructive.
- Discuss ideas and code without attacking or demeaning people.
- Respect privacy and avoid sharing employee or contributor personal information.
- Give useful context in feedback and accept good-faith corrections.
- Respect third-party creators and asset licenses.

## Unacceptable behavior

Harassment, discrimination, threats, intimidation, doxxing, repeated unwanted contact, deliberate disruption, sexualized attention without consent, and retaliation for raising concerns are not acceptable.

## Maintainer response

Maintainers may remove harmful content, pause a discussion, or restrict participation to protect contributors and keep project spaces useful. Responses should be proportionate and may range from a warning to temporary or permanent exclusion.

## Reporting

Report conduct concerns privately to the maintainer through the contact method on the `@brajesh31` GitHub profile. Include relevant links or context and avoid sending sensitive information unnecessarily. For a security concern, use [SECURITY.md](SECURITY.md). If the concern involves the maintainer, use GitHub's platform reporting tools.

This policy applies to repository issues, discussions, pull requests, and other spaces where someone is participating on behalf of the project.
